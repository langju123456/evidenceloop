# 同一模型读什么证据，分析师才更容易拿到对的数字？

D17，运行前由 Codex 为公开开发案例制定。用户未亲自选择试验臂。四题涵盖宁德时代全年和第四季度现金流，以及 Apple FY25 同比和增量贡献。固定模型、轮次、提示、最大上下文和生成上限，每题每臂一次。这里判断特定干预是否有帮助，不重建历史运行。题目必须给数字才算交付；在不完整证据前谨慎弃答单列记录，不算捏造。真实输入 token 和耗时单独报告。

| 选项 | 从分析师角度的收益及代价 | 本轮 |
|---|---|---|
| A 直接给数值行 | 便宜，跨页时年份与季度标签可能丢失 | 实跑，刻意缺表头的代理对照 |
| B 同样的行附原始列头 | 不删数字，只恢复期间标签；比 A 略长 | 实跑 |
| C 人工挑相关行且保留列头 | 可估计理想取证后还剩什么错误；需人工先验 | 实跑，诊断上限 |
| D 给整份报告 | 减少召回缺失，但干扰多，容易超上下文 | 暂缓 |
| E 自动混合检索及重排 | 更像应用真实流量，索引与过滤因素较多 | 等 ForgeFlow 版本对照 |
| F 比例交给公式工具执行 | 减少算术错，仍需选择正确分母 | 归因清楚后给产品侧候选 |
| G 先让用户点选财年或季度 | 解决歧义，但给明确的问题增加交互 | 本轮问题已明确 |
| H 展示两份候选草稿请人裁决 | 高风险题受益，人工成本较高 | 等实际审阅反馈 |
| I 先教模型正确示范再跑 | 改变提示，效果可能来自示范记忆 | 新一轮同条件实验 |
| J 用 LoRA 学习选证据或分母 | 可能迁移，需跨文档锁测并检查遗忘 | 未启动 |

每种做法用同样 4 道题、每题单次、同一个本地模型版本与生成参数。保留全部原始响应、真实提示、耗时、token、格式失败与弃答。每道题实际需要的上下文长度不同；同预算指相同次数和上限。候选按题轮换顺序，墙钟耗时包含冷热启动及其他本机负载。效果用逐题增损解释，不作统计显著性推断。Apple 未提供计算工具，选错行和算术错需要结合实际输出再区分。

## 实际结果

2026-11-23 在本机已有 Ollama 的 forgeflow-qwen3-8b-ctx16k:latest 上完成 12 次真实推理。全部为公开人工摘录输入，未调用业务工具。本轮非历史现场重演。冻结规则下 A 为 0/4 核准，B 为 1/4 核准、1/4 待核，C 为 2/4 核准。相对 A，B 修好全年，C 修好全年及季度，均无原已核准样本退化；A 本身没有核准样本，不能据此概括无回归。

| 输入 | 输入 / 输出 token 合计 | 四题墙钟合计 | 关键观察 |
|---|---:|---:|---|
| A 仅数值行 | 949 / 306 | 37.873 秒 | 两道现金流题弃答；贡献计算还选了错误基期 |
| B 恢复原始列头 | 1139 / 318 | 38.155 秒 | 全年答对；季度数值对但只引用数值页 12，仅页组证据待核 |
| C 人工筛选相关行 | 903 / 316 | 39.744 秒 | 两道现金流均核准；Apple 两题依然出错 |

Apple 增速三臂都抄了年报披露的整数 14%，与要求原金额重算并保留两位小数的 13.51% 不一致。贡献率 B 和 C 的输入完全一致；模型均写出正确的 12,989 和 25,126，却分别回答 24.45% 与 24.38%，正确舍入是 51.70%。即使相同配置和种子也有运行波动。两臂结果不能解释为人工选行对这一题造成差异。这里推荐保存列头及来源，并把计算交给可验证的工具。尚无样本支持投资训练。电耗和人工复核成本未知，外部调用费为零。所有结果为单模型、四道公开开发题。
