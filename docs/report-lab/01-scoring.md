# 一份带页码的数字，能算作回答了分析师的问题吗？

实验 D16，由 Codex 设计、标注、执行并推荐。用户授权实施，未参与逐题标注或裁决。以下筛选规则写于运行比较器之前。

| 选项 | 分析师得到什么、可能付出什么 | 本轮取舍 |
|---|---|---|
| A 有答复且带页码 | 最快找到可点的来源，容易放过错列 | 实跑，作为现有粗筛的代理 |
| B 引用页冻结摘录出现回答数字 | 能拦住部分虚构数字，错季度也可能命中，算出来的比例可能没印过 | 实跑 |
| C 独立复算数值和单位 | 能发现错分母或错量纲，碰巧答对或引用别处仍会过 | 实跑 |
| D 独立复算并核对能支撑口径的页组 | 接受合法的不同取证路径，缺证时允许待定；建参考表要工时 | 实跑 |
| E 每句话逐格签收 | 比 D 更能辨认同页多行取错，现有历史回执只有页码 | 等上游提供稳定格定位 |
| F 要求回答列出公式并验证操作数谱系 | 防止错公式碰巧给对数，点值题无需强制写公式 | 等带计算轨迹的任务 |
| G 替换某一格后重跑 | 可查模型是否依赖正确证据，会增加推理时间 | 留作开发集归因 |
| H 财务审核人盲评 | 能处理近义口径和解释质量，需要独立人力 | 留作校准 |
| I LLM 按 rubric 复核 | 覆盖开放式论述，需测漏判及位置偏差 | 等人工校准集 |
| J 查询环境确认审批和实际收件 | 换版本或重复投递会被抓到，单道数值问答没有这些状态 | 接 HorizonBench 回执后引入 |

所有候选读同一版公开开发题、回答、页级引文和原表摘录，每种每条仅评一次，零新增推理。C/D 的私有参考按公司、财年、期间、指标和单位手工锁定。分母为所有观察，另报真实历史模型和脚本构造样本；已知错误与证据超时分别保留。筛选顺序为减少错答放行、保留正确例、证据不足时可弃判。不同方法使用的信号不同正是本实验变量，未知成本记 null。此实验不给模型排名。

## 开发结果

固定 14 条，其中两条是 ForgeFlow 归档的真实模型输出（宁德时代错、Apple 产品毛利率对），12 条是 Codex 构造的对照，含 2 次模拟证据读取超时。Codex 读原表标记 6 对、6 错、2 待定。单标，样本挑选且评分器按这两份文档设计。

| 方法 | 与三态标注一致 | 放过确定错误 | 将待定判对 | 将正确判错 |
|---|---:|---:|---:|---:|
| A 有页码 | 6/14 | 6 | 2 | 0 |
| B 摘录出现数字 | 7/14 | 3 | 1 | 2 |
| C 独立数值与单位 | 11/14 | 1 | 2 | 0 |
| D 数值与支持页组 | 14/14 | 0 | 0 | 0 |

B 对计算比例出现退化，因为这两个正确百分数没有逐字印在原表上。C 放过了引用宁德时代却回答 Apple 的一条构造案例。D 识别了真实错答，保留真实正确回答，并对缺失表头或超时且数值无误的情况给出待定。错数和读取超时同时出现时，确定的错误仍保留。推荐 D 作为单数值题开发门槛。结果不证明模型读过正确格子，也不代表长文或线上任务准确率；当前完整表头页和数值页是人工核对的可接受证据路径，未标注的同文档页保留待定。E–J 均未实测。未取得第二位审核者裁决。
