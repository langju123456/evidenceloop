# D26：终态训练集拟合探针

本探针只回答一个前置问题：保存到磁盘、重新加载后的 D25 适配器，是否能在它实际见过的 Dell/Cisco 动作上作出全部 64 个受限动作选择。它不会使用 Apple、腾讯、茅台或 Oracle，也不训练新候选。

固定矩阵为 32 个训练委托 × canonical/rotated 两种菜单 × 原模型、D22 LoRA、D25 LoRA 三个 arm，共 192 次首次前向。每个 arm 只加载一次；每个格只运行一次，不重试、不覆盖。每格归档完整 prompt、A–F logits、受限选择、全词表 top token、目标 token NLL、目标相对其余五个合法动作的 margin、模型/适配器哈希和输入 token 数。

D25 的实际监督格是 64 格（两种菜单各 32）。若 D25 小于 64/64，下一轮唯一候选固定为保持 D25 其余条件不变、仅把损失改成六个合法字母 token 上的交叉熵的 0.6B、64步实验；若为 64/64，下一轮唯一候选固定为同协议的本地缓存 1.7B 模型。该分支选择在看到结果前写入 `freeze.json`；D26 本身不运行任一候选。

即使 64/64，也只说明该小型训练矩阵被拟合，不能说明对新公司、真实用户或线上流程泛化。
